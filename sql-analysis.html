Bank analysis in SQL

The peer comparison, warning screens and failure back-test from the bank health monitor, written as SQL. Each query below ran against the same FDIC data that feeds the dashboard, and the tables under each query are its actual output.

Data model

Four tables are loaded into SQLite: banks (one row per institution and its group), quarters (call-report figures by bank and quarter), cutoffs (one row of screen cutoffs, chosen by the back-test) and obs (screen inputs for banks that failed and banks that survived). A small grid table lists the alternative cutoffs tested.

Method

The queries are in sql/bank_analysis.sql and are executed by scripts/run_sql.py after each weekly data refresh. The medians, flag shares and back-test rates here match the figures on the bank health monitor, which computes them separately in JavaScript, so each result is checked two ways.
