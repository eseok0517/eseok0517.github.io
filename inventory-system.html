Supply Room Inventory System

A supply-room inventory system that runs in the browser. Operators scan items in and out, counts and reorder points update from the log, and a dashboard reports value, usage and low-stock items across rooms. It started as an Excel/VBA tool I built during an internship; this version removes that tool’s main limits and adds usage-based reordering.

All items, prices and names are synthetic and created for this demo. Changes you make are stored only in this browser.

Rules the system applies

  • A line needs a name, a known barcode, a unit type that item supports, and a whole-number quantity above zero. Blank quantity counts as 1.
  • Pieces = quantity × the item’s pieces per unit (box, pack, roll or individual). Prices are per piece, so line total = pieces × price.
  • Current inventory = physical count + pieces scanned in − pieces checked out.
  • Reorder point = lead time (months) × monthly usage. Status is REORDER at or below it and OUT at zero or less. The suggested order restores lead time plus one month of usage.
  • Days of supply = current pieces ÷ (monthly usage ÷ 30).
  • Check out is blocked when it would take more pieces than are on hand, so counts never go negative from scanning.
  • Importing identifies a log row by room and checkout ID, or by room, order, barcode and direction, so the same file can be imported twice safely.
