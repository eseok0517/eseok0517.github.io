Do market regimes affect the next 12 months of S&P 500 returns?

Compared the S&P 500’s next-12-month return across yield-curve, inflation, and credit regimes, using public FRED data refreshed weekly by an automated workflow.

    Data and method

    Source: . Series: S&P 500, 10Y-2Y Treasury spread, CPI, and high-yield credit spread. Daily series use the last valid observation in each completed month. Credit data is optional for the longer yield-curve sample; each regime table uses its own available observations. The pipeline is a short Python script run by a scheduled GitHub Actions workflow, which saves the raw downloads and the computed results in the repository.
