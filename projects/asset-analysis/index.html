The business question

What needs attention, and why?

Start with data quality

A missing audit date is a verification gap. A duplicate ID is a record-control issue. Neither, by itself, proves that an asset needs to be replaced.

Then review operating risk

Age, useful life, condition, and maintenance costs can identify assets for closer inspection. The exception export keeps the supporting records visible.

Recommendation: Resolve missing IDs, dates, costs, and duplicate records before relying on portfolio totals. Then review high-maintenance or poor-condition assets with operations.

Implementation

Make the result traceable to the register.

Import and map

Accept a CSV or Excel register, suggest column matches, and let users correct the mapping. Asset ID and cost are required fields.

Calculate and export

Normalize fields, apply editable assumptions and targets, calculate 10 KPIs, then export cleaned records or the exceptions list.

Prototype limits: Useful-life defaults and thresholds need company policy. The tool does not model disposal proceeds, taxes, downtime, or repair-versus-replace cash flows. Review source records before making accounting adjustments.
