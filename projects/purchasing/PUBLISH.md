# Publish to your existing GitHub Pages portfolio

The supplied ZIP mirrors the repository layout. It replaces `index.html` with the same existing portfolio plus the new purchasing-project card, preserves `style.css`, and adds `projects/purchasing/`.

From a local checkout of `eseok0517/Portfolio`:

1. Copy the ZIP's `index.html` and `projects/` folder into the checkout root.
2. Review `git diff` and `git status`.
3. Run the analysis and verification commands in README.md if desired.
4. Commit and push the reviewed changes to the branch configured for GitHub Pages (the repository currently uses `main`).
5. Confirm GitHub Pages deployment succeeds, then open the project through your portfolio's new case-study link.

No Pages configuration or existing site content outside the inventory-project card has been changed. The Power BI guide is included, but no finished PBIX is claimed.
